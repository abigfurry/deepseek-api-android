# 使用教程：导入聊天记录 & 充值 API 余额

> 本文档面向「DeepSeek API 版本」App 用户。App 是**非官方客户端**，只负责用你自己的 API Key 调接口，不提供账号、不代收费用。

---

## 一、导入聊天记录

### 1. 先导出（在旧设备 / 旧安装上做）

1. 打开 App → 左上角 **≡** 打开侧边栏 → 底部 **设置**
2. 进入 **数据管理**
3. 点 **导出聊天记录**
4. 系统文件选择器会让你选保存位置，默认文件名 **`dsclone-chats.json`**（也可以自己改名）
5. 保存到手机上（例如「下载」目录），再通过微信/QQ/数据线/网盘传到新设备

> 导出的文件是一个 JSON 数组，每一项是一个会话（`title` / `messages` / `updatedAt` 等字段），里面包含消息正文、思考内容、附件名、分支变体（variants）等。

### 2. 再导入（新设备 / 重装后）

1. 装好 App，先按开屏页填入 **API Key**（导入的历史不会包含 Key）
2. **≡** → **设置** → **数据管理** → 点 **导入聊天记录**
3. 选择刚才那个 `dsclone-chats.json`
4. 成功后底部会提示 **「已导入 N 个会话」**
5. 回到侧边栏，会话会按时间排序出现（同 id 的会话会被覆盖，新会话追加到最前面）

### 3. 常见问题

| 现象 | 原因 / 解决 |
|---|---|
| 提示「导入失败」 | 文件不是本 App 导出的 JSON（例如是官方 App 的导出格式，字段不同）→ 需转换后导入 |
| 只导入了部分会话 | 文件被截断 / 手动编辑过 JSON（多余逗号）→ 用 JSON 校验器检查 |
| 导入后看不到 | 会话按 `updatedAt` 排序，旧的会话可能在下方；用抽屉顶部搜索标题 |
| 想合并两台设备的记录 | 同 id 覆盖、不同 id 追加；可以先把两个导出文件手动合并成一个 JSON 数组再导入 |
| 图片/附件丢失 | 导出只保存**文件名与引用**，不打包图片本体；附件需要在原设备上另存 |

> 小提示：建议每隔一段时间「导出聊天记录」留一份备份，卸载 App 会清空本地数据。

## 二、充值 API 余额（给 DeepSeek 官方 API 账户）

App 本身**不收钱**，对话是直接打到你自己的 API 账户上，所以余额要在 **DeepSeek 开放平台**充值。

### 1. 打开开放平台
- 网页：<https://platform.deepseek.com>
- 手机浏览器也可以，建议电脑上操作更稳

### 2. 注册 / 登录 + 实名认证
- 用手机号或邮箱注册并登录
- 按平台要求完成 **实名认证**（个人/企业）。没实名认证通常无法充值、也可能限额

### 3. 创建 API Key
1. 左侧 **API keys** → **创建 API key**
2. 名字随便填，创建后**立刻复制**（只显示一次）
3. 形如 `sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`

### 4. 充值
1. 左侧 **充值 / Top up**：<https://platform.deepseek.com/top_up>
2. 选择金额，用 **支付宝 / 微信支付** 付款（海外用户可用 PayPal / 银行卡）
3. 到账后在 **账单 / Billing** 查看明细：<https://platform.deepseek.com/transactions>
4. **对公汇款**只支持企业用户（一般仅 +86 手机号注册的企业账号）

### 5. 查询余额
- 网页：账单页/用量页可以看到余额与消费
- App 内：**设置 → API 与模型 → 查询余额**（会调用平台余额接口，需要 Key 有效）

### 6. 填进 App
1. **≡** → **设置** → **API 与模型**
2. 服务商选 **DeepSeek**
3. **API Key** 粘贴 `sk-...`
4. **模型** 选 `deepseek-chat`（或平台的其它可用模型）
5. 返回聊天页发一条消息测试

### 7. 常见问题

| 现象 | 原因 / 解决 |
|---|---|
| `请求失败（HTTP 401）` | Key 错/过期/被删 → 回平台重建 Key 再粘贴（注意别带空格、中文引号） |
| `请求失败（HTTP 402）` / `Insufficient Balance` | **余额不足** → 按上面第 4 步充值 |
| `请求失败（HTTP 429）` | 触发限流 → 等一会儿再发，或降低并发 |
| `HTTP 400 ... 请改用 /v1/responses` | 你用的是第三方中转站且停了 chat/completions → **设置 → API 与模型 → 接口类型 → Responses API** |
| 余额有但一直失败 | 检查模型名是否该账号可用；检查服务商/API 地址是否匹配（DeepSeek 官方是 `https://api.deepseek.com`） |

> 余额不会过期（赠送余额有单独有效期，见账单页）。开发调试时注意：长上下文 + 深度思考会明显更耗额度。

## 三、用第三方中转站（不是官方账号）怎么充值？

中转站由各站自行运营，**充值方式各不相同**，一般在他们网站后台「充值/购买额度」处，同样支持支付宝/微信，或提供卡密。
本 App 只需要在 **设置 → API 与模型** 里把：

- **服务商**：选「自定义」
- **API 地址**：填中转站给的 Base URL（例如 `https://xxx.com/v1`）
- **API Key**：填中转站发的 key
- **接口类型**：若该站提示停用了 chat/completions，就选 **Responses API**

即可使用。充值与退款请找对应站点客服 —— 与官方平台无关。
